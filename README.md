### 操作方法 / How to Use


Tab キーで箇条書きを作成できます（複数回押すと階層が深くなります）。

Pressing Tab creates a bullet point. Pressing it multiple times increases the indentation level.


箇条書きの状態で Enter を押すと、同じ箇条書きスタイルの新しい行が自動で作成されます。

When you press Enter while in a bullet point, a new line is created with the same bullet formatting.


箇条書きの状態で Backspace を押すと、箇条書きを解除するか、階層を一段階戻します。

Pressing Backspace while in a bullet point will either remove the bullet or decrease the indentation level by one.
